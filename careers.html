Career & Job Opportunities

Where a Computer Engineering degree can lead.

RoleWhat they do
Computer EngineerDesigns and integrates hardware and software systems across the full computing stack, from circuit-level components to system-level applications.
Embedded Systems EngineerDevelops firmware and low-level software to control microcontrollers, integrated circuits, and dedicated hardware components within standalone devices.
IoT EngineerDesigns and connects physical sensor nodes, edge hardware, and cloud communication protocols to build automated IoT ecosystems
Software EngineerWrites, tests, and maintains application code, systems software, and user interfaces across digital platforms.
Hardware EngineerArchitects, tests, and optimizes physical circuit boards, microchips, and electronic components for computing devices.
Network EngineerConfigures, optimizes, and maintains physical and virtual network infrastructure, switches, routers, and voice channels.
Systems EngineerManages the holistic integration, reliability, and technical architecture of complex hardware-software systems throughout their lifecycle.
Cybersecurity EngineerImplements defensive protocols, encryption, and threat analysis to safeguard networks, devices, and digital assets from attacks.
Data EngineerBuilds and manages scalable data pipelines, storage systems, and databases that convert raw data into usable analytical streams.
AI / Machine Learning EngineerDevelops algorithms, trains neural networks, and optimizes machine learning models on hardware for automated decision-making.
Cloud EngineerDeploys, manages, and scales virtual server infrastructure, storage resources, and hosted services in cloud environments.
DevOps EngineerAutomates software deployment, bridges development with IT operations, and maintains continuous integration and delivery (CI/CD) pipelines.
Robotics EngineerIntegrates mechanical actuators, embedded control software, and sensor feedback loops to build autonomous robotic systems.
Technical Support EngineerTroubleshoots, diagnoses, and resolves complex technical issues across computing hardware, software platforms, and network connections.
Research & Development EngineerExplores, prototypes, and tests experimental technologies to invent new computing solutions and push engineering capabilities forward.
